# 沿途未定 · Roam 品牌规范

品牌更新：2026-10-12（Asia/Taipei）；资料整理：2026-10-13。状态：名称、图标与字标已实装，最近品牌发布记录为提交91d13cb。后续提交和发布按用户当次要求执行。

## 固定名称

- 中文：沿途未定。
- 英文：Roam；视觉字标使用小写 roam。
- 完整显示名称：沿途未定 · Roam。
- 产品说明：双人城市冒险。
- 首页文案：下一站，走着看。
- 描述：两个人，一部手机。抽一张卡，让下一站带来意外。

品牌文本统一在 `src/lib/config/brand.ts` 管理。浏览器标题、description、苹果主屏幕显示名、页头、通行证、备份文件名和构建后的 manifest 使用这份配置。旧名称不再作为品牌展示；普通语句中的“一起走走”仍可作为自然语言使用。既有历史和玩家自定义名称不做字符串替换，新行程的默认名字为“沿途的一天”。

## 图标与字标

采用路线形小写 r：竖线向右弯出，前方留一个分离圆点，表示尚未决定的下一站。小写 roam 为原创几何线条轮廓，无外部字体依赖。

- 主色：深蓝 `#17354D`。
- 底色：纸白 `#FFF8E9`。
- 页头内联 SVG 使用 `currentColor`，随现有主题文字色适配。
- App 图标采用完整纸白底，避免把系统裁切形状画进图片。
- maskable 图标的全部前景位于中心 80% 安全圆内，兼容圆形、方形和圆角裁切。
- 图标附近至少保留图标宽度的 1/8 空白，不拉伸、不额外添加阴影或渐变。
- 品牌可访问名称使用“沿途未定 · Roam”，装饰路径不重复朗读。

矢量唯一来源：`src/lib/ui/brand-art.mjs`。页头组件和 PNG 纪念票直接使用同一套路径。

生成资源：

- `public/brand-symbol.svg`：透明背景独立符号。
- `public/brand-wordmark.svg`：透明背景英文矢量字标。
- `public/icon.svg`：带底色的浏览器图标。
- `public/icon-180.png`：苹果触屏图标。
- `public/icon-192.png` / `public/icon-512.png`：PWA 图标。
- `public/icon-maskable.png`：512px 安全裁切图标。

修改路径后执行 `node scripts/brand-assets.mjs`，再提交 SVG 和 PNG。脚本复用项目的 Playwright；Windows 默认使用已安装的 Edge，其他系统默认 Chromium，也可通过 `CITYWALK_TEST_BROWSER` 指定。日常构建不需要启动浏览器生成图标。

## 实装与兼容

网页页头使用路线图标、roam 字标和中文名，首页更新品牌文案。纪念票页和导出的 PNG 显示品牌，备份下载采用新的中文前缀。

网址、GitHub 仓库、`/citywalk/` 部署路径、package 内部标识、manifest `id/start_url/scope`、IndexedDB `citywalk-for-two/state/current`、全部存储 key 和更新频道保持原值。名称更新通过原 Service Worker 的内容版本机制发布；用户显式应用更新，旧记录继续读取。

旧版“一起走走”和讨论候选“岔路来信”等已退出正式命名。后续文档或新页面统一使用本规范。
