## 视觉方向

围绕两位探险者进入城市关卡的既有世界设计。延续帽子、背包、晴日城市、青色线索、金色指南针和 5:7 任务牌，让 UI 与现有九类任务插画相互衔接。Roam 字标与中文品牌继续使用既有矢量来源。

| 用途 | 色彩与做法 |
| --- | --- |
| 页面与卡纸 | 米白 `#FFF8E9`、纸白 `#FFFDF5`；保持任务文本清楚 |
| 主要文字与卡框 | 深蓝 `#17354D` / `#19394F`，清晰的实体边框 |
| 主行动 | 暖金 `#F1C76B`，深蓝文字，按压阴影 |
| 探索与成就 | 绿色 `#376F62`，点亮印章与完成状态 |
| 对话与线索 | 蓝色 `#366B91`，青色线索继承场景原画 |
| 挑战与强调 | 橙色；用于合作印章和任务得分 |

文字、日期、编号、任务内容和状态均由 HTML 或 Canvas 排版，图片只承担美术。任务卡正文保留 16–17px，说明与主要辅助信息按 12px 起步；邮票上的微缩装饰字不承担必要操作说明。

## 页面设计

- **首页**：出发入口与试玩放在主视觉旁，晴日城市入口明确表达游戏主题；通行证、任务类型邮票与最近旅程形成后续入口。
- **准备出发**：短途、半日、自由、试玩使用清楚的模式选择；三个旅程主题配对应邮票，说明仍是真实的玩法文本。
- **任务卡**：保留九类插画与原有精确匹配、5:7 正反面、滑动与按钮替代；加像素盖章，操作入口按可用高度避开导航与安全区。
- **收藏册**：邮票与任务内容并列，保留喜欢、不抽、完成过和自定义功能。三类任务的类别色与卡面一致。
- **冒险日志**：新增像素纪念册封面、实际旅程统计与成就印章，每段历史配主题邮票。未获得印章显示灰色轮廓，点亮状态由已有真实规则计算。
- **旅程纪念票**：场景、主题邮票、合作盖章组合成顶部纪念画面；保存图片沿用完整任务、主题快照、分支与回忆，多页内容继续分页。

## 查看与维护

卡背使用原深蓝城市路线与金色指南针 `deck-pattern.svg`，保留纯粹的完整图案。主题名显示在旅程顶部，完整玩法说明收进折叠的旅程工具；牌面只承担翻牌入口，操作提示放在牌外。

自定义卡编辑器复用现有九张任务插画，提供原生图像与文字组成的实时预览；桌面右侧停留，手机紧凑显示。草稿恢复后同步预览，保存后将新卡呈现在视口内。手机出发栏同步显示实际选定主题。

运行 `npm run preview -- --port 5198`，打开 `http://127.0.0.1:5198/citywalk/`。修改源码后先运行 `npm run build`。

原图已保存时，使用 bundled sharp 重制 WebP：

```powershell
node scripts/prepare-postal-art.cjs C:/Users/28337/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/sharp
```

无需重新生图，也无需安装额外依赖。重制后运行 build/check 更新离线资源哈希。当前 1 MiB 预算余量较小，后续加入美术应先整理重复 CSS 与资源，保留主图和任务文字的清晰度。
