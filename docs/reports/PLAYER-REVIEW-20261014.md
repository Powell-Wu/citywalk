# 沿途未定 · Roam：第三方玩家评审

2026-10-14（Asia/Taipei），评审版本 `r-d4a6d340274f`，提交 `957be6c`。当日只读核对正式网站版本，与本地试玩一致。

**游戏已经有吸引人尝试的外观、顺畅的基本流程和有价值的纪念票。当前最影响质量的是配合规则不够显眼、主题玩法差异不够稳定，以及收藏目标很快耗尽。下一轮投入应集中在这三点。**

本次在独立浏览器入口走完三卡「街角线索」和四卡「默契挑战」的界面流程，检查首页、准备、翻牌、奖励、收尾、收藏、日志与编辑器。视觉覆盖默认桌面、390×844和320×700；卡池与主题同时核对当前源码。两条记录均标记为评审示例。任务的户外趣味与两人交谈感受，留给后文的实际试玩检验。

## 玩家会喜欢什么

- **第一眼有吸引力。** 米白票面、深蓝卡背、像素城市和邮票印章属于同一套视觉语言；通行证已经有完整票面的感觉。建议保留当前方向。
- **能很快开始。** 手机首页首屏能看到「直接试玩」，零消费、不计分、三张卡说明清楚；第一张任务立即出现。第一卡后的线索/声音选择给了两人参与感。
- **好的任务能自然带动互动。** 找颜色、拍笑脸、轮流接故事都有具体对象和结束条件，适合边走边做。可以把这些任务作为后续内容的标准。
- **收尾确实留下了纪念。** 旅程名称、日期、邮票、任务回顾和一句话组成完整票面；日志有纪念册封面，值得保存和回看。
- **基础操作有弹性。** 暂停、换卡、跳过和不计分照顾不同节奏；从设置返回后，原出发选择完整保留。自定义卡的九张插画与实时预览足以支持第一版创作。

## 建议及优先级

### P1：把「怎么一起做」和「完成」放到玩家马上看见的位置

390×844的第一张试玩卡，主区域主要展示插画、标题和一句提示；「谁先」「怎么交换角色」「做到什么算完成」位于首屏下方，而完成按钮藏在「更多操作」里。320×700时，「找一个最适合发呆的位置」的“两分钟”提示也从牌面移到折叠详情。

玩家可能只看标题便开始做，或者把游戏理解为一组随手打勾的任务。建议在卡片可见区域保留一条核心配合指令和完成条件；「完成」作为常驻主按钮，换卡为次按钮，稍后和跳过继续收起。滑动保留为快捷操作。完整背景和长说明仍可折叠。

例如颜色卡首屏直接写：**「你选颜色 → 对方先找 → 交替找到三件」**。优先调整现有文字区留白和插画比例。

验收：新玩家只看首屏，能说清谁先、接着做什么、什么时候完成；不用寻找手势或展开菜单即可完成一次操作。

### P1：让两种主题拥有可辨认的做法

当前默契主题18张任务中，7张有独立的双人配合段落；6张探索任务全部也在观察城市池中。实际抽到的「找一个最适合发呆的位置」只有找位置、坐一会的提示，默契主题承诺的猜测与角色交换没有体现。轮流续写故事则清楚得多。

建议先精修6张默契探索任务，并为主题中的对话任务补齐短步骤。每张默契任务至少出现一个「先猜后揭晓、交换角色、共同选择」动作；观察主题围绕实际城市细节做发现和分享。

同一个发呆地点任务可以这样区分：

- 观察城市：各发现一个让这里适合休息的细节，交换观察。
- 默契挑战：各自选位置，先猜对方会选哪处，再揭晓理由。

每个主题目前只有6张对话卡，半日每局会抽3张。近期降权有帮助，扩内容时应优先扩这些小池，并提供同一任务的不同做法。

验收：玩家连续体验两种主题后，能用具体动作说出差别，而不只记住名称和票面颜色。

### P1：把邮票和纪念章变成下一局的目标

三卡试玩后已获得3枚纪念章中的2枚。再走完四卡默契流程后，最后一枚进度为7/8；再完成一种新任务就会获得全部三枚。纪念票已经漂亮，但目前的长期目标只支撑很少的局数。

建议复用现有美术，新增「完整观察旅程」「完整默契旅程」两枚主题章，以及16种不同任务的阶段目标。收尾时明确展示这次新获得什么、下一枚怎样获得；票面下提供下一种主题的直接入口。

收藏册可以用「我的纪念 / 任务卡池」两个视图，前者突出已收集和待获得的章，后者保留喜欢、不抽与自定义卡。这样已经完成的内容有展示位置，任务筛选也继续好用。

验收：第一局结束能看到一个具体的新目标；第二至第五局仍有不同纪念可期待。用少量有意义的目标检验效果，再决定是否扩大收藏系统。

### P2：保持准备出发的上下文

「看看我们的奖励」会跳到设置页顶部，玩家先看到版本与更新、声音；点返回又回到首页。重新进入准备页时，草稿还在，但这段来回打断了出发节奏。

建议在准备页就地展开三档奖励预览与编辑。若继续跳转设置，应直接定位奖励区，并返回原准备页。玩法主题选择可增加一张代表任务预览，帮助玩家理解差别。

全局「主题」实际是外观选择，目前只有一个可用外观，另一项暂未开放。改名「外观」并移到设置，可减少它与「观察城市 / 默契挑战」的混淆。

验收：玩家查看或编辑奖励后，可以直接出发；选主题时能看到要做的具体事情。

### P2：收束尾声反馈，增加每张任务的新鲜感

本次正式流程第三卡、第四卡、保存收尾分别触发三次宝箱弹窗。宝箱有仪式感，尾声连续确认会稀释庆祝；保存结束后，按钮仍写「继续冒险」，此时实际已经进入记录详情。

建议中途达档用简短提示，收尾集中展示最高奖励与新纪念。最后按钮改成「收好这一程」或「查看纪念票」，接续实际页面状态。

16张对话卡目前共用同一幅树荫插画。一局抽两至三张对话时，会反复看到同一画面。后续美术可优先增加少量对话情境变体，让不同任务更容易被记住。

### P2：照顾不同同行关系和实际地点

首页用「两位同行者」，默认奖励和部分对话却使用「约会」。朋友或刚认识的两人可能需要更多跳过。室内/户外筛选也无法区分公园、街区和咖啡馆，进店任务在公园里仍可能不合适。

建议提供轻量的「轻松 / 熟悉彼此」内容偏好和中性的奖励预设；换卡时可选「不适合这里 / 今天不想做 / 刚做过」，帮助当局减少同类不合适任务。先检验这些选择是否改善实际使用，再决定更细的地点设置。

## 下一轮建议范围

| 顺序 | 交付 | 玩家价值 |
| --- | --- | --- |
| 1 | 首屏配合提示、常驻完成按钮、准备页奖励原地查看 | 第一次玩就知道怎么做，减少操作打断 |
| 2 | 精修6张默契探索任务，补齐主题对话的角色步骤 | 主题选择对应具体不同玩法 |
| 3 | 主题纪念章、16种任务目标、结算后的下一程入口 | 第一局结束有理由再打开 |

先完成这组内容，再用5对玩家实际走一段路，其中至少3对体验第二局。记录以下结果：

1. 至少4对在无讲解情况下完成第一张任务，并能说出配合规则。
2. 至少4对能描述两主题不同的做法。
3. 记录换卡理由，重点检查地点不合适与问题不想回答。
4. 第二局记录是否主动打开、是否只是为了审核被邀请；结束后问「下一次还想做什么」，让玩家先自由回答。
5. 观察是否为了看步骤反复盯手机，以及收尾取名、弹窗是否打断交谈。
